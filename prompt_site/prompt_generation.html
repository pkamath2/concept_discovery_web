Dataset construction

Generating the single-source prompt dataset

We used Claude Haiku 4.5 (claude-haiku-4-5-20251001) to write 150,000 natural-language prompts for a text-to-audio model (Stable Audio Open). Every prompt describes a single sounding source performing one physically plausible action, placed in one of sixteen acoustic environments. This page documents the exact system prompt, the user-message template, and the generation settings for reproducibility.

Generation configuration

Modelclaude-haiku-4-5-20251001 (Claude Haiku 4.5)
Final dataset150,000 prompts — train 120,000 / val 15,000 / test 15,000

System prompt

Identical for every request (and cached across the batch).

You write short natural-language prompts for a text-to-audio model (Stable Audio Open).

You are given ONE sound source (a label) and ONE acoustic environment. Produce a set of distinct prompts, each describing that ONE source making a sound.

Hard rules:
- EXACTLY ONE sounding source per prompt. Never introduce a second source, a background sound, or an unrelated object. The source is only the given label.
- Choose an action, manner, or process that is PHYSICALLY PLAUSIBLE for that source. If the label already names an action (e.g. "Bark", "Air Brake", "Zipper"), realize that action directly; you may vary its manner (a single bark vs. rapid barking; a short zip vs. a slow drawn-out zip) but never change what the source is.
- If the label is a broad source (e.g. "Dog", "Bird", "Car"), pick a sound it naturally makes (dog -> barking, howling, growling, whimpering; car -> engine idling, door slamming, tires on gravel). Do NOT attach an action that the source cannot produce.
- Place the sound in the given environment ONLY when that is plausible for the source. If the environment makes no physical sense for this source (e.g. ocean surf in a tiled bathroom), ignore it and use a neutral space or none. Never force an implausible room.
- Describe the SOUND, not a visual scene or a story. Present tense. No brand names. Do not start with "a sound of" or "the sound of". Vary sentence structure across the prompts.
- Each prompt is 5 to 15 words, and MOST should be 5 to 10 words. Keep them short and concrete, the way a Stable Audio Open prompt reads. Each ends with a period.

Motion (use for SOME prompts, only when plausible):
- Give SOME prompts a sense of MOTION of the single source: moving left to right or right to left across the stereo field, approaching or receding, passing by, or moving at different speeds (slow, fast). This still describes ONE source moving — it is NOT a second source. A dog running from left to right while barking is one source; a car driving past is one source.
- Apply motion ONLY when it is physically plausible for this source. Sources that do not travel — stationary appliances, fixed objects, ambient textures (e.g. an air conditioner, a zipper, rain) — must stay still. For those, keep every prompt stationary and never invent movement.
- A stationary environment (e.g. a small padded booth, a tiled bathroom) is not a good fit for motion; prefer motion in open or passing spaces.

Across this set, vary the action, intensity, tempo, perspective (near/far), and motion so the prompts are clearly distinct from one another.

Output ONLY a JSON array of objects, nothing else. Each object is {"prompt": "<the prompt>", "motion": true|false}, where "motion" is true ONLY if that prompt describes the source moving. Example:
[{"prompt": "A dog barks sharply in an open yard.", "motion": false}, {"prompt": "A barking dog runs from left to right across the field.", "motion": true}]

Acoustic environments

Sixteen environments, applied one per request so each label is spread evenly across all spaces. The model is instructed to ignore an environment that is implausible for a given source.

  • close-miked and dry, with no room reverb
  • in a small carpeted room
  • in a small tiled bathroom
  • in an average living room
  • in a large empty hall with long reverb
  • in a large warehouse
  • in a concrete stairwell
  • in a wooden-floored studio
  • outdoors in an open field
  • outdoors in a dense forest
  • outdoors on a quiet street
  • in a narrow corridor
  • in a cavernous underground space
  • in a small padded recording booth
  • heard from a distance across an open space
  • up close in a quiet room

User message

One message per request, filled from the label, environment, and a per-request diversity seed:

Sound source: {label}
Acoustic environment: {environment}
Write {n} distinct prompts, each 5-15 words (ideally 5-10). Aim for about {motion_target} of them to convey plausible motion of the source; keep the rest stationary. If this source cannot move, keep all stationary. Diversity seed: {seed} (use it to make this set different from other sets for the same source).

A concrete example (label Dog Barking, first environment, 25 prompts, seed 0):

Sound source: Dog Barking
Acoustic environment: outdoors in an open field
Write 25 distinct prompts, each 5-15 words (ideally 5-10). Aim for about 8 of them to convey plausible motion of the source; keep the rest stationary. If this source cannot move, keep all stationary. Diversity seed: 0 (use it to make this set different from other sets for the same source).

Model output & post-processing

The model returns a strict JSON array, one object per prompt: {"prompt": "…", "motion": true|false}, where motion is true only when that prompt describes the single source moving. Responses are parsed, each prompt is validated (5–15 words) and de-duplicated, then the pool is shuffled (seed 42) and split 80/10/10, trimmed to 120,000 / 15,000 / 15,000. Each finalized record:

{
  "id":              "p_0000001",
  "prompt":          "A barking dog runs from left to right across the field.",
  "sounding_object": "Dog",
  "environment":     "outdoors in an open field",
  "motion":          true,
  "split":           "train"
}

Design constraints

  • Exactly one sounding source per prompt — no second source, background, or unrelated object.
  • Physically plausible action — if the label names an action it is realized directly (its manner may vary); a broad label uses a sound the source naturally makes.
  • Environment as the only extra axis — the source is placed in the given space only when plausible, otherwise a neutral space is used.
  • Motion of the single source — about 30% of prompts convey the one source moving (left–right, approaching, receding, passing), applied only to sources that can travel; stationary sources stay still.
  • Prompt style — present tense, describe the sound not a visual scene, no brand names, no “sound of” opener, 5–15 words ending with a period.
